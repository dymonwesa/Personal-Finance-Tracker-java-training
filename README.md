# Wallet Tracker (Учёт доходов и расходов)

Консольное Java-приложение для учёта финансов: добавление транзакций (доход/трата), просмотр списка, расчёт баланса и просмотр последней операции.

## Стек

- Java
- Без сборщика (Maven/Gradle не используются) — проект запускается напрямую из IntelliJ IDEA

## Как запустить

1. Открыть проект в IntelliJ IDEA
2. Запустить класс `Main` (кнопка **Run** ▶️)

## Как пользоваться

В консольном меню доступны пункты:

1. **Добавить транзакцию** — выбрать тип (доход/трата), ввести сумму, выбрать категорию (еда/транспорт/обучение/отдых), добавить описание
2. **Вывести список транзакций** — показать все добавленные транзакции
3. **Получить баланс** — сумма доходов минус сумма трат
4. **Вывести последнюю транзакцию** — показать самую последнюю добавленную запись
5. **Выйти**

## Структура проекта

```
src/
 ├── Main.java              — точка входа, запускает ConsolUI
 ├── ui/
 │   └── ConsolUI.java       — консольное меню и обработка ввода
 └── model/
     ├── Transaction.java    — транзакция: сумма, тип, категория, описание, дата
     ├── WalletService.java  — хранение списка транзакций, добавление, баланс, печать
     ├── Type.java            — enum: INCONE (доход), EXPENSE (трата)
     └── Category.java        — enum: FOOD, TRANSPORT, LEARNING, RELAXING
```
